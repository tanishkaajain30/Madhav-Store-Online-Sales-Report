# Madhav Store Online Sales Report

## Project Overview
Developed an interactive Power BI dashboard to analyze online sales performance and generate business insights.

## Tools Used
- Power BI
- Power Query
- DAX

## Key Insights
- Sales performance by category
- Customer purchasing trends
- Regional sales analysis
- Profitability insights
- KPI monitoring

## Dashboard Features
- Interactive filters and slicers
- KPI cards
- Sales trend analysis
- Product category performance
- State-wise sales visualization
